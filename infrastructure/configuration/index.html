    Configuration¶

    Environment variables¶

    Variable Required Default Purpose
    DATABASE_URL Yes — Supabase / Postgres DSN for nodes and pairing
    REDIS_ADDR No localhost:6379 Redis host:port
    CLICKHOUSE_ADDR No localhost:9000 ClickHouse native protocol
    CLICKHOUSE_DATABASE No default Database name
    CLICKHOUSE_USER No default User
    CLICKHOUSE_PASSWORD No empty Password
    DEBUG_MODE No unset When 1, auth succeeds even if Redis credit lookup fails
    DISCORD_TOKEN No unset If set, starts the Discord bot

    ClickHouse init failure is logged as a warning; Supabase init failure is fatal.

    Listener ports¶

    Configured in code / Compose port mappings:

    Port Mapping in Compose Service
    1080 1080:1080 SOCKS5 (started in main)
    8081 8081:8081 HTTP CONNECT (HTTPProxy implemented; ensure a listener is started in main for production)
    8080 8080:8080 Prometheus /metrics, HTML /stats
    8443/udp 8443:8443/udp QUIC nodes

    Redis¶

    Used for:

    • Buyer API-key → credits lookup
    • Streams / pub-sub for connection features (AI pipeline)

    Compose enables AOF persistence under .logs/redis-data.

    Supabase / Postgres¶

    Stores:

    • Connected node metadata and activity
    • Pairing requests (node_connect_requests) claimed by the website

    The website (separate repo) consumes the same project via realtime.

    ClickHouse¶

    Stores session-level features for analytics and future anomaly detection. Migrations live under clickhouse/migrations/ and run via the migrate Compose service.

    TLS / QUIC¶

    At startup the server generates a self-signed certificate and listens with:

    • InsecureSkipVerify: true (dev-oriented)
    • ALPN protocol name: turbo-proxy

    For production, inject a proper certificate and tighten verification on the node client.

    Compose excerpt¶

    backend:
  build: .
  ports:
    - "1080:1080"
    - "8081:8081"
    - "8080:8080"
    - "8443:8443/udp"
  environment:
    - REDIS_ADDR=redis:6379
    # - DATABASE_URL=${DATABASE_URL}
